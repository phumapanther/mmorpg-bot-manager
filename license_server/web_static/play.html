🎴 ศึกไพ่รูน

🎴 วิธีเล่นศึกไพ่รูน

ทิ้งไพ่ในมือให้หมดก่อนคนอื่น — คนชนะได้แต้มจากไพ่ที่เหลือในมือคนอื่น

วางไพ่ยังไง

  • สีตรง กับสีของกอง — หรือ เลข/ท่าตรงกัน ก็วางข้ามสีได้
  • ไพ่ที่วางได้จะมี ขอบทองเรืองแสง · ที่วางไม่ได้จะหรี่ลง
  • ลากไพ่ขึ้นมาจากมือแล้วปล่อย — ไพ่จะดูดเข้ากองเอง ไม่ต้องเล็งให้ตรง
  • ไม่มีไพ่วางได้เลย → กดที่กองไพ่ บนโต๊ะ (จะมีขอบเหลืองเรืองบอก)
