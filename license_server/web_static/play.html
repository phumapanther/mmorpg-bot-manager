🏦 ธนาคาร

ทุกธุรกรรมมีค่าธรรมเนียมตามยอด — ระบบจะแสดงให้ดูก่อนยืนยันทุกครั้ง

💡 ค่าธรรมเนียมยิ่งโอนเยอะยิ่งแพง (5% ถึง 50%) — แบ่งโอนหลายครั้งเสียถูกกว่าโอนก้อนใหญ่ครั้งเดียว

🧈 ทองคำแท่ง

แปลงเงินในธนาคารเป็นแท่งทองเก็บในกระเป๋า — ขายคืนที่นี่ได้ราคาดีกว่าร้านค้า

⚠️ ทองคำแท่งอยู่ในกระเป๋า จึงมีโอกาสถูกโจรฉกระหว่างผจญภัย ต่างจากเงินในธนาคารที่โจรปล้นได้แต่ไม่หมดเกลี้ยง

👑 ร้านขายยศ

ซื้อยศเผ่าพันธุ์และคลาสอาชีพด้วยทองในเกม — ยศจะถูกมอบให้ในเซิร์ฟ Discord อัตโนมัติ

โครงหน้าเท่านั้น — ยังไม่เชื่อมข้อมูลจริง (เฟส 7) ของจริงจะดึงรายการยศจาก auto_trade_roles ในคอนฟิก และให้บอทเป็นคนมอบยศ เพราะเว็บแจกยศ Discord เองไม่ได้

🎰 กาชาสุ่มยศ

จ่ายทองหนึ่งครั้ง สุ่มยศหายากจากตู้ — ได้ของซ้ำก็มี ลุ้นกันไป

โครงหน้าเท่านั้น — ปุ่มยังไม่หักเงินจริง (เฟส 7) ของจริงจะมีอนิเมชันเต็ม: ลูกแก้วสั่น → แสงพุ่ง → การ์ดยศพลิกเปิด → เอฟเฟกต์แรงตามระดับยศที่ได้

🎲 ทอยเต๋ารับของรายวัน

ทอยเต๋าเดินบนกระดาน ตกช่องไหนได้ของช่องนั้น — เดินครบรอบรับรางวัลใหญ่

🎲 ทอยได้อีก 3 ครั้งวันนี้ · รีเซ็ตเที่ยงคืน · โควตาใช้ร่วมกับในดิส

โครงหน้าเท่านั้น — ยังไม่ได้ของจริง (เฟส 8) ของจริง: กระดานเปลี่ยนหน้าตาและรางวัลตามธีมอีเวนต์ประจำสัปดาห์ · รางวัลเป็นทองจำนวนน้อย EXP บัฟชั่วคราว และไอเทมที่มีอยู่แล้วในเกม
