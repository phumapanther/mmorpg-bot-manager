💎 เติมเกม

เติมทองผ่าน PromptPay — โอนแล้วแอดมินตรวจสอบและอนุมัติ ทองเข้าธนาคารในเกมอัตโนมัติ

ต้องล็อกอินก่อนเติมเกม — ล็อกอินด้วยไอดี Discord

วิธีเติมเกม 3 ขั้น

1️⃣ ล็อกอินเว็บด้วยไอดี Discord (ปุ่มด้านบน)
2️⃣ ใส่จำนวนเงิน → สแกน QR PromptPay โอนได้เลย
3️⃣ แอดมินตรวจยอด → ทองเข้าธนาคารในเกมอัตโนมัติ

สแกนจ่ายด้วยแอปธนาคาร

โอนแล้วแนบสลิปไว้เลย แอดมินจะตรวจเร็วขึ้น (ดูสถานะได้ที่หน้าโปรไฟล์) — รายการ #
