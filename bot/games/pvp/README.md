# ⚔️ หมวด PVP — สนามรบผลัดเทิร์น

รื้อโครงสร้าง 2026-09-02 — ย้ายมาจาก `bot/pvp/` ให้เข้าโครงเดียวกับ
`bot/games/casino/` ที่ทำไปแล้วขั้นก่อน เพื่อให้แจกงานทีม PVP ดูแลโฟลเดอร์นี้
ได้โดยไม่ชนกับทีมอื่น

```
bot/games/pvp/
├── terrain.py    แผนที่ — สร้างเกาะ/ตึก/ต้นไม้ ตรวจพื้นเดินได้
├── physics.py    ฟิสิกส์ — เดิน กระโดด ตก จมน้ำ (คำนวณฝั่งเซิร์ฟเวอร์เท่านั้น)
├── weapons.py    อาวุธ/สกิล — melee/lob/beam/self ตาม CLASS_SKILLS ของเกมหลัก
├── rooms.py      ห้อง/ทีม — เปลือกบางบน bot/lobby.py (ห้อง/รหัส/ที่นั่งอยู่ที่ lobby.py)
└── match.py      ตัวคุมแมตช์ (ใหญ่สุด) — รวมทุกอย่างเข้าด้วยกันเป็นเกมจริง
```

พึ่งข้างนอกแค่ 2 ตัว: `bot.lobby` (ล็อบบี้กลาง) กับ `license_server.web_db`
(ฐานข้อมูล) — ไม่พึ่ง cog ดิสคอร์ดเลย

## กฎการแบ่งงาน

- **ห้าม import จาก `bot/games/casino/`** และกลับกัน — คนละทีมกัน คุมด้วย
  `tests/test_pvp_structure.py` ถ้าใครข้ามทีมโดยไม่ตั้งใจ เทสจะแดงทันที
- **ห้าม import จาก `bot/cogs/`** — PVP เป็นเกมแยกที่เข้าจากเมนูเว็บ ไม่ยุ่งกับ
  ลูปผจญภัยเดิม (ดู `docs/plan-2026-08-17-pvp-lobby.md`)
- ไฟล์เก่าที่จุดเดิม (`bot/pvp/{match,terrain,physics,weapons,rooms}.py`)
  เหลือไว้เป็น **สะพาน** ให้โค้ด/เทสที่ยัง import ทางเดิมอยู่ไม่พัง — โค้ดใหม่
  ให้ import จากที่ใหม่ในนี้ตรง ๆ ห้ามดัดโค้ดในนี้ให้อ้อมกลับไปหาสะพาน

## ⚠️ เขียนเทสหมวดนี้ต้องรู้: `import *` ไม่ดึงชื่อขึ้นต้นด้วย `_`

เทส `test_worms_*.py` เรียกฟังก์ชันภายในข้ามไฟล์ผ่านสะพานอยู่ (เช่น
`match._explode`, `match._use_skill`, `terrain._standable`,
`physics._blocks`) — ถ้าเพิ่มฟังก์ชัน `_` ตัวใหม่ในไฟล์พวกนี้แล้วมีเทสอื่น
เรียกข้ามไฟล์ ต้อง `from bot.games.pvp.xxx import _ชื่อฟังก์ชัน` เพิ่มเองใน
สะพานที่ `bot/pvp/xxx.py` ไม่งั้นหายเงียบ ๆ (`AttributeError` ตอนรันเทส)

เคยพลาดมาแล้วตอนรื้อโครงสร้างคาสิโน (09-02) จนต้องให้โค้ดอ้อมเรียกผ่านสะพาน
ซึ่งทำให้เกิด import วนกลับ — ห้ามทำซ้ำ ให้แก้ที่สะพานแทน
