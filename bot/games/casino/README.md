# หมวดคาสิโน — ใครดูแลโฟลเดอร์ไหน

รื้อโครงสร้าง 2026-09-02 — แยกโฟลเดอร์ต่อเกม เพื่อให้แจกงานคนละคนดูแลได้
โดยไม่ชนกัน (ก่อนหน้านี้ UNO มีโฟลเดอร์ตัวเองอยู่แล้ว แต่แบล็กแจ็ค/สล็อต/ไฮโล
ลอยรวมกันอยู่ใน `bot/` — แก้ทีเดียวกระทบหลายทีม)

```
bot/games/casino/
├── shared.py          ← ของกลางหมวดคาสิโน (_take_bet) — ห้ามก๊อปไปไว้ที่อื่น
├── uno/                ← คนดูแล UNO
│   ├── deck.py         สำรับ 108 ใบ
│   ├── rules.py        กฎวางไพ่
│   ├── engine.py       ลำดับเทิร์น/การ์ดพิเศษ
│   ├── bot_ai.py        บอทนั่งโต๊ะ
│   ├── table.py        โหมดซ้อมกับบอท
│   └── room.py         โหมดเดิมพันหลายคน
├── blackjack/           ← คนดูแลแบล็กแจ็ค
│   └── core.py         แจกไพ่/ตุกติก/ตัดสิน — เก็บสถานะข้าม Discord/เว็บ
├── slots/               ← คนดูแลสล็อต
│   └── core.py         หมุนวง/เรทจ่าย/ตุกติก
└── hilo/                 ← คนดูแลไฮโล
    └── core.py         ทอยเต๋า/เรทจ่าย/ตุกติก
```

## กฎการแบ่งงาน

- **ห้าม import ข้ามโฟลเดอร์เกม** (uno ↔ blackjack ↔ slots ↔ hilo) — คุมด้วย
  `tests/test_casino_structure.py` ถ้าใครข้ามทีมโดยไม่ตั้งใจ เทสจะแดงทันที
- ของกลางที่หลายเกมใช้ร่วมกัน (ตอนนี้มีแค่ `_take_bet`) อยู่ที่ `shared.py`
  เท่านั้น ไม่ก๊อปซ้ำ
- ไฟล์เก่าที่จุดเดิม (`bot/blackjack_core.py`, `bot/casino_core.py`,
  `bot/cards/uno_*.py`) เหลือไว้เป็น **สะพาน** ให้โค้ด/เทสที่ยัง import
  ทางเดิมอยู่ไม่พัง — โค้ดใหม่ให้ import จากที่ใหม่ในนี้ตรง ๆ

## หนี้ทางเทคนิคที่ทิ้งไว้ (อ่านก่อนแก้ hilo)

`bot/games/casino/hilo/core.py::play_hilo` ยังอ้อมเรียก `roll_hilo` ผ่าน
`bot.casino_core` (สะพานเก่า) แทนที่จะเรียกตรงในไฟล์เดียวกัน — เพราะ
`tests/test_casino_core.py` มี `monkeypatch.setattr(cc, "roll_hilo", ...)`
ผ่านชื่อสะพานเดิม ถ้าเรียกตรงจะไม่เห็นแพตช์ (ดูคอมเมนต์ในไฟล์)
ลบท่านี้ได้เมื่อย้ายเทสไป import จาก `bot.games.casino.hilo.core` ตรง ๆ แล้ว
