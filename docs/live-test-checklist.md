## 🖼️ เพิ่ม 03 ส.ค. — ภาพพิกเซลอาร์ตประกอบเหตุการณ์ (~175 ภาพ)

> หลักการ: ภาพหาย/โหลดพลาด = ข้อความเดิมไม่มีภาพ **เกมต้องไม่พังเด็ดขาด** — ถ้าเจอ error ที่โยงกับภาพ แจ้งทันที

- [ ] `!play` เดินจนครบ 7 อีเวนต์ (มอน/หมู่บ้าน/หีบ/ดันเจี้ยน/NPC/กับดัก/ทางสงบ) → **มีภาพทุกแบบ และภาพตรงธีมทวีปที่ยืนอยู่**
- [ ] ย้ายทวีป (ตั๋ว/ยานสุ่ม) แล้วเดินซ้ำ → ภาพอีเวนต์เปลี่ยนตามทวีปใหม่
- [ ] สู้มอน: เทิร์นแรกเห็น**ภาพมอนตรงตัวที่เจอ**มุมขวาบน embed → เทิร์น 2-3 ภาพยังอยู่ **ไม่มีการอัปโหลดซ้ำ** (ข้อความไม่หน่วงขึ้น)
- [ ] เดินรวด ×5 บนทางสงบ → ภาพโชว์เฉพาะข้อความสุดท้าย ไม่สแปมทุกก้าว
- [ ] `!use 24/25/26` (ใบเชิญบอส) → เห็นภาพ summon ตอนใช้ และตอนบอสโผล่ตอนเดิน
- [ ] `!use 66` (กับดัก), เข็มทิศ/เหยื่อล่อ/ธูป → เห็นภาพตอนใช้สำเร็จ
- [ ] `!use 22` (วาปเมือง) / `!use 23` (วาปดันเจี้ยน) / เรดาร์ → เห็นภาพหมู่บ้าน/ดันเจี้ยน/หีบของทวีปปัจจุบัน
- [ ] ตายแบบไหนก็ได้ (สู้แพ้/กับดัก/special) → เห็นภาพ 👻 ตอนตาย, กดเกิดใหม่ → เห็นภาพ ✨ แสงชุบชีวิต
- [ ] `!marry` แล้วอีกฝ่ายกดตกลง → เห็นภาพงานแต่ง
- [ ] ขึ้นยานข้ามทวีป → เห็นภาพยาน (เรือเหาะ/เรือ/ประตู/ขบวนม้า) ตอนเจอ + ภาพทวีปตอนถึง
- [ ] เจอ special event ประจำทวีป (เช่นพายุหิมะ/ภูเขาไฟ) → มีภาพประกอบ
- [ ] วันจันทร์/เปลี่ยนธีม → ประกาศธีมมีภาพประกอบธีม
- [ ] สวมอาร์ติแฟกต์ / อาวุธตำนาน / กระเป๋าเวทมนตร์ → เห็นภาพตอนสวมสำเร็จ
- [ ] **เน็ตช้า (มือถือ 4G):** ภาพโหลดได้ ปุ่มกดไม่หน่วงเกินรับได้ (ภาพ ~11-15KB/ใบ)

## 💰 ขั้นที่ 2 — เส้นทางเงินและของ (พลาดแล้วผู้เล่นเสียของจริง)

**ตลาดผู้เล่น**
- [ ] `!market sell 30 5000` → ✅ ของ**หายจากกระเป๋าทันที** (เช็ค `!bag`)
- [ ] อีกคน `!market buy <เลข>` → คนซื้อได้ของ + เงินลด / คนขายได้เงิน**เข้าธนาคาร** (หัก 5%)
- [ ] `!market cancel <เลข>` ของตัวเอง → ✅ ของกลับเข้ากระเป๋า
- [ ] ลองซื้อของตัวเอง → ต้องโดนปฏิเสธ
- [ ] **ให้ 2 คนกดซื้อชิ้นเดียวกันพร้อมกัน** → ต้องมีคนได้คนเดียว อีกคนขึ้น "มีคนซื้อตัดหน้า" และ**เงินไม่ถูกตัด**

**แต่งงาน + แหวน**
- [ ] `!marry @เพื่อน` ตอนไม่มีแหวน → ต้องบอกให้ไปซื้อก่อน
- [ ] ซื้อแหวน (`!shop` เลข 65) → `!marry @เพื่อน` → อีกฝ่ายกด **💔 ปฏิเสธ** → ✅ **แหวนต้องยังอยู่**
- [ ] ขอใหม่ → กด **💍 ตกลง** → แหวนหาย, ทั้งคู่เสียค่าจัดงานคนละ 500,000
- [ ] `!profile` ทั้งสองฝ่าย → เห็นช่อง 💍 คู่หู
- [ ] `!divorce` → หย่าได้, อีกฝ่ายไม่เสียค่าหย่า

**อาร์ติแฟกต์**
- [ ] ใส่อาร์ติแฟกต์ 1 ชิ้น → ใส่ชิ้นที่ 2 → ✅ ต้องขึ้น "ช่องเต็ม" และ**ของเก่าไม่หาย**
- [ ] `!use 67` (สว่าน) → ช่อง 1→2 → ใส่ชิ้นที่ 2 ได้
- [ ] ซื้อ `!shop` เลข 68 → `!use 68` → เลือกถอด → ✅ **อาร์ติแฟกต์กลับเข้ากระเป๋า**
- [ ] เจาะจนครบ 5 ช่อง → ใช้สว่านอีก → ต้องปฏิเสธและ**สว่านไม่หาย**
