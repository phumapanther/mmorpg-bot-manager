> บล็อกที่ 1–5 คือแพตช์โน้ตเต็ม ส่วนบล็อกท้ายเป็นเวอร์ชันสั้นถ้าอยากโพสต์ครั้งเดียวจบ

## 📮 ข้อความที่ 1 — เปิดหัว + ระบบดึงคนกลับมา

```
# 🎉 อัปเดตใหญ่! — 27-28 กรกฎาคม

ยกเครื่องทั้งเกมในรอบเดียว มีของใหม่ให้เล่นเพียบ อ่านให้จบแล้วเข้าไปเก็บของรอไว้เลย 👇

## 📅 ภารกิจรายวัน + ล็อกอินต่อเนื่อง  `!daily`
เข้ามาเล่นทุกวันมีของแจก ไม่ต้องทำอะไรพิเศษ — ระบบนับความคืบหน้าให้เองจากการเล่นปกติ
• ล่ามอน 10 ตัว · ออกเดินทาง 20 ครั้ง · ล้มบอส 2 ตัว · ใช้ไอเทม 3 ครั้ง
• เคลียร์ครบทุกข้อ รับโบนัสอีกก้อน
• 🔥 **ล็อกอินติดกัน** 3/7/14/30 วัน มีรางวัลไล่ระดับ — ครบ 30 วันได้ **ถุงเต๋าเทพี** (อาร์ติแฟกต์!)
• ขาดวันเดียวนับใหม่หมดนะ แต่สถิติสูงสุดยังอยู่ให้อวด

## 🎟️ ซีซั่นพาสรายเดือน  `!season`
แต้ม = EXP ที่หาได้ในเดือนนั้น มี 7 ขั้น รางวัลใหญ่ขึ้นเรื่อย ๆ
• 🆓 **สายฟรีทุกคนได้** — ไม่ต้องจ่ายก็มีของเก็บ
• ⭐ สายพรีเมียมเปิดเพิ่มได้ ซื้อแล้ว **ย้อนเก็บขั้นที่ปลดไปแล้วได้ทันที**
• ขึ้นเดือนใหม่ = ซีซั่นใหม่ เริ่มนับกันใหม่หมด

## 🗓️ อันดับประจำสัปดาห์  `!top`
• แต้ม = EXP ที่หาได้ในสัปดาห์นั้น — ทุกคนเริ่มเท่ากันทุกวันจันทร์
• ปิดอันดับเช้าวันจันทร์ **ท็อป 3 รับทองเข้าธนาคารอัตโนมัติ**
• `!top` รวมอันดับทุกหมวดไว้หน้าเดียวแล้ว กดปุ่มสลับดูได้เลย (สัปดาห์นี้ / เศรษฐี / เลเวล / นักแชท / ออนไลน์)
```

## 📮 ข้อความที่ 2 — สะสม + สังคม

```
## 🏅 ความสำเร็จ + ตำแหน่งอวด  `!ach`
13 รายการให้ไล่เก็บ — และ **ระบบนับย้อนหลังให้อัตโนมัติ**
ใครเล่นมานานแล้ว เปิดครั้งแรกอาจได้รัวหลายอันพร้อมทองก้อนโตทันที
ปลดแล้วได้ **ตำแหน่ง** เลือกติดโชว์ใต้ชื่อในโปรไฟล์ เช่น 「ผู้พิชิตทุกทวีป」「มหาเศรษฐีพันล้าน」

## 🐾 สัตว์เลี้ยง 8 ตัว  `!pet`
**ล้มมอนแล้วลุ้นจับมาเลี้ยง!** ยิ่งมอนโหด ตัวที่ได้ยิ่งแรง — ติดตัวได้ทีละตัว ช่วยหนุนลูกเต๋าตอนสู้
• 🟢 สไลม์น้อย / 🦇 ค้างคาวจิ๋ว (เต๋า +1) — จากมอนธรรมดา
• 🐺 ลูกหมาป่า / 👺 ภูตน้อยจอมกวน (+2) — จากมินิบอส
• 🦅 ลูกกริฟฟิน / 🪨 โกเลมจิ๋ว (+3) — จากบอสใหญ่
• 👻 เงาลึกลับ (+4) — จากมอนลับ
• 🐉 **ลูกมังกร (+5)** — จากมอนไร้พ่ายเท่านั้น
ตัวที่มีแล้วจะไม่ออกซ้ำ ตัวแรกติดให้อัตโนมัติ

## 🏪 ตลาดผู้เล่น  `!market`
ขายของให้เพื่อนร่วมเซิร์ฟด้วยทองในเกมได้แล้ว!
`!market sell <เลขไอเทม> <ราคา>` ลงขาย · `!market buy <เลขรายการ>` ซื้อ · `!market cancel` เอาคืน
ของออกจากกระเป๋าทันทีที่ลงขาย (กันขายซ้ำ) · เงินคนขายเข้าธนาคาร · มีค่าธรรมเนียมนิดหน่อย

## 💍 ระบบคู่หู  `!marry @คน`
**ต้องซื้อ 💍 แหวนแต่งงาน ที่ `!shop` ก่อนถึงจะขอได้** — ราคา 50,000,000 ทอง ของแบบนี้ต้องจริงจังหน่อย 😎
ชวนใครสักคนเป็นคู่ (อีกฝ่ายต้องกดยืนยัน) แหวนจะถูกสวมให้เขาตอนตกลง — แล้วได้โบนัสรางวัลจากการล่าทั้งคู่
🔥 **ถ้าคู่ของคุณเข้ามาเล่นวันเดียวกัน โบนัสจะเพิ่มขึ้นอีกเท่าตัว** — ไปตามคู่มาเล่นได้แล้ว!
*(ขอไม่สำเร็จ/โดนปฏิเสธ ไม่เสียแหวน · แต่แต่งแล้วหย่าไม่ได้แหวนคืนนะ)*
```

## 📮 ข้อความที่ 3 — ระบบใหญ่ที่มาก่อนหน้า

```
## 🏰 ระบบกิลด์  `!guild`
ตั้งกิลด์ของตัวเองได้แล้ว — ได้ **ยศกิลด์สีสุ่ม** + **บ้านกิลด์ (ห้องเสียงส่วนตัว)** อัตโนมัติ
มีคลังกิลด์ให้สมาชิกฝาก หัวหน้าถอน/จ่ายได้ · เปลี่ยนชื่อกิลด์ได้ (มีค่าธรรมเนียม)

## ⚔️ กิลด์วอร์  `!warguild @หัวหน้ากิลด์อื่น [เดิมพัน]`
ท้าศึกกิลด์ต่อกิลด์ **เดิมพันด้วยคลังกิลด์จริง** ผู้ชนะรับกองกลางทั้งก้อน
เปิดห้องรบชั่วคราวให้สองกิลด์ 30 นาที พิมพ์ `!fight` รัวได้เลย
เจอทหาร +1 · หัวหน้าศัตรู +10 · ทำลายป้อม/ปราสาทศัตรูหักแต้มหนัก

## 🎯 ล่าค่าหัว  `!bounty`
ใครสติติดลบ = กลายเป็นอาชญากรมีหัวราคา ใครก็ล่าได้
ฆ่าอาชญากร **ไม่เสียสติ ไม่มีเวรกรรม แถมได้สติคืน** — ตำรวจกลายเป็นอาชีพทำเงินแล้ว

## ⚔️ ธีมสงครามฝ่าย มนุษย์ ↔ ปีศาจ  `!war`
ธีมสัปดาห์แบบใหม่ — ระหว่างผจญภัยจะเจอ **แชมเปี้ยนฝ่ายตรงข้าม** ที่ใช้ชื่อผู้เล่นจริง
โค่นได้ ทอง ×2 EXP ×1.5 และได้แต้มให้ฝ่ายตัวเอง สู้กันทั้งสัปดาห์

## 📕 สมุดสะสมมอนสเตอร์  `!bestiary`
ล้มมอนแรงค์ไหนในทวีปไหน ช่องนั้นติ๊ก ✅
ครบ 1 ทวีป +100,000 · ⭐ ล้มไร้พ่าย +200,000 · **ครบทั้งเล่ม +1,000,000 + ยาครอบจักรวาล**

## 🌍 พาบอทไปเล่นเซิร์ฟอื่นได้แล้ว
ตัวละครผูกกับตัวคุณ ไม่ใช่เซิร์ฟ — เลเวล ทอง ของ ทุกอย่างตามไปด้วย
(ฟีเจอร์เต็ม เช่น ร้านค้า คาสิโน กิลด์ รางวัลรายวัน ยังต้องกลับมาเล่นที่เซิร์ฟหลักนะ)
```

## 📮 ข้อความที่ 4 — เล่นง่ายขึ้นเยอะ

```
## 🕹️ เล่นง่ายขึ้นเยอะ — แทบไม่ต้องพิมพ์คำสั่งแล้ว

**ปุ่มโผล่ทุกที่**
• ปุ่ม 🕹️ เมนู ต่อท้ายทุกหน้าอีเวนต์ — กดเปิดกระเป๋า/ธนาคาร/โปรไฟล์ได้กลางทาง
• 🏦 ธนาคาร ฝาก/ถอน/โอน ผ่านฟอร์ม ไม่ต้องพิมพ์จำนวนเอง
• 🔨 **คราฟผ่านปุ่ม** — โชว์เฉพาะสูตรที่วัตถุดิบครบ ไม่ต้องจำรหัสไอเทม
• 🧱 ปุ่มขายวัสดุทั้งหมดรวดเดียว · 🗑️ ปุ่มทิ้งของ
• 🧪 **ใช้ไอเทมกลางไฟต์ได้จากในหน้าต่อสู้เลย**
• 🏦 🪪 ปุ่มลัดธนาคาร/โปรไฟล์ในหน้าหมู่บ้าน

**⏩ ปุ่มเดินต่อ ×5**
เดินรวดทีเดียว 5 ก้าว ข้ามช่วงที่ไม่มีอะไรให้ตัดสินใจ
เจอมอน/หีบ/กับดัก/ดันเจี้ยน หรือเลือดต่ำกว่า 30% = หยุดให้ทันที ไม่ตายฟรี

**หน้าจอใหม่หมด**
• ⚔️ หน้าต่อสู้เป็น embed — เห็นเลือดสองฝ่าย ที่มาแต้มเต๋าทุกก้อน สถานะที่ติดอยู่ ครบในจอเดียว
• 💀 หน้าตายบอกชัด 3 ส่วน: เสียอะไร / เหลืออะไร / ทำอะไรต่อ (ของในกระเป๋าปลอดภัยเสมอ)
• 🪪 โปรไฟล์แบ่ง 3 หน้า สลับด้วยปุ่ม · 🎒 กระเป๋าจัดกลุ่มตามประเภทของ
• 📖 **คู่มือในเกม** `!codex` — เลือกหัวข้อจากเมนู ครบ 10 หมวด รวมของใหม่ทั้งหมด
```

## 📮 ข้อความที่ 5 — คอนเทนต์ใหม่ + สมดุล + แก้บั๊ก

```
## 🩸 ของใหม่ในโลก
• สถานะ **เลือดไหล** — แผลเขี้ยวปีศาจ เสียเลือดทุกก้าว แก้ด้วย 🩹 ผ้าพันแผล
• สถานะ **สปอร์เห็ด** — สะสมครบ 3 สแตกแล้วบานทั้งร่าง
• 🧪 **ยาสุ่มของแม่มด** — พนัน 50/50 ได้บัฟดีหรือสถานะร้าย
• 🥩 เหยื่อล่อมอน (เจอมอนถี่ขึ้น) · 🕯️ ธูปไล่มอน (เดินทางสงบ) — ล้างฤทธิ์กันเองได้
• ไอเทมล้างสถานะเพิ่มอีก 5 ชิ้น — ไม่มีสถานะไหนที่แก้ไม่ได้อีกแล้ว
• ⚔️ **บัฟวอริเออร์**: Shield Bash ลดดาเมจ 60% 4 เทิร์น + สะท้อนกลับ 20% ·
  Heavy Strike ทอยได้ 18+ = **คริติคอล ดาเมจ ×3**

## ⚖️ ปรับสมดุลจากผลเทสจริง
• **ลดโอกาสโดนมอนตีติดสถานะลงยกแผงทุกแผนที่ (~40%)** — ติดถี่เกินไปจริง ขอโทษด้วย 🙏
• ธีมสงครามฝ่าย: เจอแชมเปี้ยนบ่อยขึ้นเท่าตัว (หายากเกินไป)

## 🐛 แก้บั๊ก
• 🏪 ร้านค้าในหมู่บ้านแสดงของไม่ครบ (หายตั้งแต่เลข 59) และปุ่มกลับหาย — **แก้แล้ว**
• 🌿 ใช้มีดตัดเถาวัลย์แล้วยังหนีไม่ได้ — **แก้แล้ว** (ไอเทมทุกชิ้นมีผลทันทีกลางไฟต์แล้ว)
• ⏩ ปุ่มเดินต่อ ×5 กดแล้วค้าง — **แก้แล้ว**
• 🏡 ปุ่มในหน้าหมู่บ้าน/ร้านค้าตายเงียบถ้าดูนาน — **แก้แล้ว** (ขยายเวลาเป็น 10 นาที + บอกเหตุผลถ้าหมดอายุ)
• ⚔️ กิลด์วอร์: ห้องรบค้าง / เตือนแล้วสู้ต่อไม่ได้ / ไม่ประกาศผล — **แก้ครบแล้ว**
• 🔌 บอทดับเองกลางอากาศโดยไม่มีใครสั่ง — **เจอต้นเหตุแล้วและแก้แล้ว**

ขอบคุณทุกคนที่ช่วยเทสและรายงานบั๊กมานะครับ 🙏
พิมพ์ `!codex` เพื่ออ่านคู่มือของใหม่ทั้งหมด แล้วเจอกันในเกม!
```
