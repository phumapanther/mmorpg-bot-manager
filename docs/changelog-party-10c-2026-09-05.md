## 3. ตัดสินใจเอง 2 ข้อ (แจ้งเจ้าของเกมแล้ว รอเปลี่ยนได้)

### 3.1 อายุสถานะ 5 รอบ กำหนดที่เหตุการณ์ ไม่ใช้ `default_turns` ของเกมหลัก

`frostbite` ของเกมหลักตั้งไว้ **999 รอบ** เพราะธีม Absolute Zero เสกใส่ซ้ำทุกก้าวอยู่แล้ว
ความหนาวที่นั่นเป็น "สภาพแวดล้อม" ไม่ใช่บาดแผลจากภัยที่เจอหนเดียว
เอามาใช้ตรง ๆ = เลือดไหลไปตลอดการเดินทาง (ล้างได้แค่หมู่บ้าน/NPC/ดันเจี้ยน)

**เส้นแบ่งที่ใช้:** เหตุการณ์เป็นเจ้าของ *"นานแค่ไหน"* · เกมหลักเป็นเจ้าของ *"เจ็บแค่ไหน"*

- ปรับที่ Panel: `party.disaster.status_turns` (ค่าเริ่ม 5)
- อยากกลับไปใช้ของเกมหลัก: ลบ `m.get("turns")` ออกจาก `room._disaster_payout`
  (เทส `test_ภัยพิบัติกำหนดอายุสถานะเอง` จะแดง ต้องลบด้วย)

### 3.2 เลือกสถานะแค่ 3 ตัวที่มี `step_damage`

`poison` (เถ้าภูเขาไฟ) · `bleed` (อุกกาบาต) · `frostbite` (พายุหิมะ)

โหมดปาร์ตี้มีกลไกเดียวคือ **"เลือดไหลต่อรอบ"** — `numb` (`player_dmg_mult`)
กับ `burn` (`combat_pct_damage`) ทำงานผ่าน hook ในไฟต์ของโหมดเดี่ยวที่โหมดนี้ไม่มี
ติดให้ก็เป็นป้ายโชว์เปล่า ๆ หลอกผู้เล่น

**ถ้าจะเพิ่มสถานะแบบอื่น** ต้องเขียน hook ในโหมดปาร์ตี้ก่อน แล้วค่อยเติมใน `disaster.KINDS`
มีเทส `test_ทุกภัยติดสถานะที่มีดาเมจต่อรอบจริง` กันลืม

## 4. บั๊กของ 10b ที่เจอตอนต่อสาย — **แก้ไปพร้อมกันในก้อนนี้**

### 4.1 🔴 ปุ่มเหตุการณ์ยิงผ่าน API ไม่ได้เลย (ร้ายแรงที่สุด)

`license_server/api_web/games/party.py` รับแค่คำสั่งใน `engine.ACTIONS`
ปุ่ม "💤 พักผ่อน" / "🔓 เปิดหีบ" ที่ commit ไปใน 10b **ตอบ 400 ทุกครั้ง** — เล่นไม่ได้เลยทั้งชุด

เทส 46 ข้อของ 10b จับไม่ได้เพราะเรียก `room.act()` ตรง ๆ ข้ามชั้น API ไปเลย

**แก้:** เพิ่ม `room.in_event(uid)` แล้วส่งคำสั่งต่อให้ `room.act` ตัดสินทั้งดุ้น
เหตุผลที่ไม่ทำลิสต์คำสั่งซ้ำที่ชั้น API: คำสั่งแบบ `buy:<item_id>` สร้างตอนรัน ลิสต์ตายตัวจะพลาด

⚠️ **สาขานี้ต้องอยู่หลัง `create/join/leave/start/again/restart` เสมอ**
ไม่งั้นชื่อคำสั่งที่ซ้ำกันจะถูกเหตุการณ์กินไปหมด (มีเทส `test_ออกจากปาร์ตี้กลางเหตุการณ์ยังได้` คุม)

**ผลข้างเคียง:** ปุ่ม "🚶 ลาไปก่อน" ของ NPC ต้องเปลี่ยนคีย์จาก `leave` → **`bye`**
เพราะ `leave` เป็นคำสั่ง "ออกจากปาร์ตี้" ของ API อยู่แล้ว

### 4.2 🔴 พื้นหลังเหตุการณ์ 404 ทุกใบ

หน้าเว็บต่อ URL เอง: `/assets/events/${ev.art}.png` → `/assets/events/village.png`
แต่ไฟล์จริงในโฟลเดอร์ชื่อ **`main_village.png`** / `frozen_village.png` (มีคำนำหน้าทวีป)
ไม่มีไฟล์ชื่อ `village.png` เปล่า ๆ สักใบใน 176 ใบ

**เทสเดิมล็อกของผิดไว้:** `assert "${ev.art}" in LOBBY` — บังคับให้หน้าเว็บต่อ URL เอง
ซึ่งคือต้นเหตุ · เขียวมาตลอดโดยไม่มีภาพขึ้นเลย (ดู `tests-that-lock-wrong-behavior` ในความจำ)

**แก้:** เพิ่ม `bot/event_images.web_url(key, continent)` — กติกาชื่อไฟล์เดียวกับฝั่งดิสเป๊ะ ๆ
ลองภาพประจำทวีปของหัวห้องก่อน → `main_*` → ชื่อเปล่า → `None` (ไม่มีก็วาดได้ไม่พัง)
เซิร์ฟเวอร์ส่ง `event.art_url` ไปให้ หน้าเว็บไม่ต่อเองอีกแล้ว

### 4.3 🟠 `bot/event_images.py` `import discord` ที่หัวไฟล์

แกนปาร์ตี้ (`room._art_url`) เรียกไฟล์นี้ → พังตอนรันบนโฮสต์เว็บที่ไม่ได้ติดตั้ง discord
เทส `test_แกนโหลดได้โดยไม่มี_discord` จับไม่ได้เพราะ import แบบ lazy ในฟังก์ชัน

**แก้:** ครอบด้วย `try/except ImportError` — ฟังก์ชันที่คืน `discord.File` จะฟ้องตอนเรียกเอง
`web_url()` ไม่ต้องใช้ discord เลย

### 4.4 🟡 แถบเลือดบนจอเหตุการณ์ไม่ลด

`_treasure_payout` / `_disaster_payout` หักเลือดในฐานข้อมูลอย่างเดียว

## 6. โครงสร้างที่รื้อระหว่างทาง

`room.py` เคยเป็น `if/else` ไล่เช็คชนิดเหตุการณ์ 4 จุด (`_ev_actions` `_ev_act` `_ev_tick` `_next_encounter`)
เติมชนิดที่ 3-4 แล้วจะเละ → เปลี่ยนเป็นแผนที่เดียว:

```python
EVENT_MODS = {"village": village, "treasure": treasure,
              "trap": disaster, "npc": npc}
```

**เพิ่มเหตุการณ์ใหม่ = เขียนโมดูลแล้วเติมบรรทัดเดียวตรงนี้** ทุกโมดูลต้องเซ็นเหมือนกัน:

```python
start(members, rng)                        options(ev, unit_id, is_host)
act(ev, unit_id, action, rng, is_host)     bot_pick(ev, unit_id)
```

มีเทส `test_ทุกโมดูลเหตุการณ์หน้าตาเหมือนกัน` ใช้ `inspect.signature` คุมไว้
(`village.py` ต้องเติม `is_host=False` เข้าไปด้วยเพื่อให้เซ็นตรงกัน)

⚠️ **ชื่อคีย์ต้องเป็นชื่อของเกมหลัก** — ภัยพิบัติใช้ `"trap"` ไม่ใช่ `"disaster"`
เพราะ `adventure_core.EVENT_LIST` กับตารางน้ำหนักที่ Panel เรียกแบบนั้น
ตั้งชื่อใหม่ = ต้องมีตัวแปลงเพิ่มเปล่า ๆ และปรับที่ Panel แล้วสองโหมดไม่ตรงกัน

## 8. ⚠️ จุดที่ยังขัดกันเอง — ยังไม่ตัดสิน

**หมู่บ้านคิดค่านอนพัก 2,000 ทอง แต่ "ออกจากปาร์ตี้แล้วเปิดใหม่ = ฟื้นเต็มฟรี" ยังใช้ได้**

ทางเลือกตอนแก้:
1. ถอด `_heal_full` ออก แล้วให้หมู่บ้าน/ไอเทมเป็นทางเดียวที่ฟื้น (ต้องกันปาร์ตี้ตันด้วย)
2. เก็บก๊อกไว้ แต่คิดค่า "ออกเดินทาง" แทน
3. ปล่อยไว้ — ยอมรับว่าหมู่บ้านเป็นแค่ความสะดวก ไม่ใช่ทางรอด
