# ✅ Checklist เทสบอทจริงเฟส D (ก่อน build แจกลูกค้า)

> รันบอทกับเซิร์ฟจริง แล้วไล่ติ๊กทีละข้อ — ข้อไหนพัง จดข้อความ error + สิ่งที่ทำก่อนพังไว้
> เตรียมก่อนเทส: ตัวละครแอดมิน 1 ตัว + ตัวละครผู้เล่นธรรมดา 1 ตัว (ต่างยศเผ่า), ใช้ `!setstatus`/`!setcontinent` เร่งสถานการณ์ได้

## 0. พื้นฐาน (ของที่พังบ่อยกับ Discord จริง)
- [ ] บอทสตาร์ท ไม่มี error ใน console, ทุก cog โหลดครบ (รวม `weekly_event`, `world_admin`, backup)
- [ ] `!play` สร้างตัวละครใหม่ได้ / ตัวละครเก่า (ไม่มี field continent/status) เข้าเกมได้ไม่พัง
- [ ] `!profile` — เห็นครบ: ทวีป, ธาตุ (พร้อมบรรทัด `✨ ติดตัว:`), อาร์ติแฟกต์, สถานะ
- [ ] `!bag` กับของ 20+ ชิ้น — ไม่ชนลิมิต 1024
- [ ] `!codex` / `!codex ธาตุ` / `!codex สถานะ` / `!codex ทวีป` แสดงครบ ไม่ error

## 1. ธาตุผู้เล่น — เช็คชื่อยศจริงทีละเผ่า (จุดเสี่ยงสุด: keyword match)
สลับยศให้ตัวเทสทีละเผ่า แล้วดู `!profile` ว่าธาตุขึ้นถูก:
- [ ] มนุษย์ → แสง+ลม | - [ ] เอลฟ์ → ไม้ | - [ ] ยักษ์ → ดิน | - [ ] คนแคระ → ดิน+ไฟ
- [ ] มังกร → ไฟ | - [ ] ภูติ → ลม | - [ ] เงือก → น้ำ | - [ ] มิ้ง → ลม
- [ ] ยศ 2 เผ่าพร้อมกัน → ขึ้น 2 ธาตุ + passive ทั้งคู่

## 2. Passive ธาตุในไฟต์จริง (ของใหม่วันนี้ — ยังไม่เคยรันจริง)
- [ ] 🔥/🌑 ตี: เห็นบรรทัด "พลังธาตุประจำตัวเสริมคมอาวุธ ×..." และดาเมจแรงขึ้นจริง
- [ ] 💧 น้ำ: ตีโดนแล้วเห็น "+HP สายธารชีวิต..." และ HP ไม่ทะลุ MaxHP
- [ ] 💨 ลม: เห็น "สายลมประจำตัวหนุนลูกเต๋า +1" ทุกเทิร์น
- [ ] 🪨 ดิน: โดนตีเห็น "ผิวศิลาดูดซับแรงกระแทก" ดาเมจเบาลง
- [ ] 🌑 มืด: โดนตีเห็น "ร่างกระหายเลือดเปราะบาง" ดาเมจแรงขึ้น
- [ ] 🌿 ไม้: เดินหลายก้าวตอน HP ไม่เต็ม → HP ค่อย ๆ ขยับขึ้นเอง (เงียบ ๆ ไม่มีข้อความ)
- [ ] ✨ แสง: ชนะไฟต์ ทอง/EXP เยอะขึ้น ~10%
- [ ] ธาตุข่มมอน: เห็น "ธาตุประจำตัวของคุณข่มธาตุศัตรู! ×1.5" (ลอง ×2.0 ด้วยยศคู่)

## 3. ทวีป + การเดินทาง (ไล่ให้ครบ 9)
- [ ] เดินจนสุ่มเจอพาหนะ (8%) → จ่ายค่าโดยสาร → ถึงแล้วรู้ปลายทาง + ปุ่ม "ไปต่อ" ขึ้นเสมอ
- [ ] `!setcontinent <key> @คน` ครบทั้ง: demon, frozen, nether, volcanic, sylvan, mechanized, skyward, ocean, main
- ต่อทวีปอย่างน้อย 1 อย่าง: - [ ] มอนธีมประจำถิ่นโผล่ | - [ ] special_event ประจำทวีปเด้ง | - [ ] frozen: ติด frostbite แวดล้อม | - [ ] nether: โดน Life Drain | - [ ] mechanized: โดน EMP ปุ่มสกิลหาย | - [ ] skyward: อีเวนต์เกาะถล่ม

## 4. สถานะ + Consumables (จับคู่ ติด→แก้)
- [ ] พิษ: ติดจากมอน/`!setstatus poison 3` → เลือดไหลรายก้าว → 🌿 ยาถอนพิษหาย (คู่กับ entangled)
- [ ] frostbite → 🏮 ตะเกียง (กัน 10 ก้าว + ติดใหม่ไม่เข้า)
- [ ] EMP → 💾 ชิป (ไฟต์ถัดไปใช้สกิลได้)
- [ ] Life Drain → 💧 น้ำมนต์ (3 ไฟต์)
- [ ] 🎲 เต๋าถ่วง: แต้มต่ำถูกดันเป็น 14 | - [ ] 🍀 โคลเวอร์: กันรากไม้ 1 ครั้ง
- [ ] 🧪 ยาพลิกธาตุ: มอนไฟต์ถัดไปเกิดเป็นธาตุที่เราข่ม
- [ ] 🥫 เสบียง: ฮีล 50% + ล้างเชื้อซอมบี้ | - [ ] ซอมบี้กัด 3 ครั้ง → แปลงร่างเป็นคลั่ง
- [ ] 🎨 ผงสีรุ้ง: เมนูเลือกสี → !profile เปลี่ยนสีจริง → ผงถูกหักตอนยืนยัน
- [ ] สาปคี่/คู่: เต๋า parity ตรงสาป → ดาเมจแป้ก/ฮีลมอน ตามชนิด

## 5. Artifact (ช่องเดียว สวมทับทำลาย)
- [ ] สวมชิ้นแรก → ขึ้นใน !profile ช่อง 🏺
- [ ] สวมชิ้นที่สอง → **ของเก่าหายถาวร** + มีข้อความเตือนชัดเจน
- [ ] 📿 สร้อยเนเธอร์ (ของใหม่วันนี้): เข้า nether โดน Life Drain → เห็น "+HP สร้อยวิญญาณกลืนพลัง..." แทนโดนดูด
- [ ] 👝 ถุงเต๋า: +1 ทุกเทิร์นถาวร | - [ ] 🎭 แว่น: ตรวจ NPC ฟรี | - [ ] 🥾 บูท: แพ้เต๋ามอนลมแล้วมีลุ้นทอยใหม่

## 6. ธีมสัปดาห์ + คำสั่งแอดมิน
- [ ] ประกาศธีมต้นสัปดาห์เด้งในห้อง weekly_event ครั้งเดียว (restart บอทแล้วไม่ประกาศซ้ำ)
- [ ] `!settheme <key>` ล็อกธีม → restart แล้วยังล็อกอยู่ → `!settheme auto` กลับสุ่มปกติ
- [ ] `!setstatus <key|clear>` / `!setcontinent` ใช้ได้เฉพาะแอดมิน (คนธรรมดาโดนปฏิเสธ)
- [ ] ธีมพิเศษ 1-2 ตัว: Blood Moon / Goddess dice / Masquerade (ตรวจ NPC ปลอม) ทำงานตามสเปก

## 6.5 ของใหม่รอบ P1+P2 (2026-07-27)
- [ ] ปุ่ม 🕹️ เมนู โผล่ท้ายทุกหน้าอีเวนต์ (ไฟต์/สมบัติ/กับดัก/NPC/เดินทาง/ฟื้นชีพ) และกดแล้วเมนูเด้งแบบเห็นคนเดียว
- [ ] เมนู → 🏦 ธนาคาร → ปุ่มฝาก/ถอน/โอน + ฟอร์มกรอกเลข (ลองโอนด้วย @เมนชั่น และไอดี) — ยอดอัปเดตถูก
- [ ] เมนู → 📖 คู่มือ → เลือกครบ 6 หัวข้อ ทุกหน้าแสดงได้
- [ ] วอริเออร์: Shield Bash เห็นข้อความสะท้อน 20% ตอนบล็อก / Heavy Strike เต๋า 18+ ขึ้น "ติดคริติคอล ×3"
- [ ] 🩸 เลือดไหล: โดนมอนทวีปปีศาจกัด → เลือดไหลรายก้าว → 🩹 ผ้าพันแผล (61) หาย
- [ ] 🍄 สปอร์: โดนมอนซิลวานตี 3 ครั้ง (เร่งด้วย `!setstatus spores 2` แล้วโดนอีกที) → เห็ดบาน เลือดไหล 5% + เต๋า −1 → ยาถอนพิษล้างสปอร์ก่อนบานได้
- [ ] 🧪 ยาสุ่มแม่มด (62): กินหลายขวด เห็นทั้งผลดี/ร้าย
- [ ] 🥩 เหยื่อล่อ (63) → เจอมอนถี่ขึ้นชัด / 🕯️ ธูป (64) → มอนหาย + ใช้ทับกัน = ตัวใหม่ล้างตัวเก่า

## 6.6 ล่าค่าหัว P4 (2026-07-27)
- [ ] `!bounty` — ไม่มีคนสติติดลบ = ข้อความสงบสุข / มี = ลิสต์เรียงค่าหัว
- [ ] ตัวเทส A กด `!att` คนปกติหลายรอบจนสติติดลบ → โผล่บนกระดาน `!bounty`
- [ ] ตัวเทส B `!att` ใส่ A: ข้อความ "การไล่ล่าอาชญากรไม่ใช่บาป — สติไม่ลดลง"
- [ ] B ฆ่า A สำเร็จ → ได้ค่าหัว + ข้อความ 🎯 + สติ B คืน +10 + สติ A รีเซ็ต 0 หลุดกระดาน
- [ ] เช็คว่าตีคนปกติยังเสียสติ/มีเวรกรรมตามเดิม

## 6.7 สงครามฝ่าย P5 (2026-07-27)
- [ ] `!settheme faction_war` → ประกาศธีมสงคราม → เดินป่าด้วยตัวละครมียศเผ่า → เจอ "⚔️ [ชื่อผู้เล่นจริง] ขุนศึกฝ่ายปีศาจ/ผู้กล้าฝ่ายมนุษย์" (~25% ของมอน)
- [ ] ชื่อแชมเปี้ยนดึงจากผู้เล่นจริงฝ่ายตรงข้ามในเซิร์ฟ (ถ้าไม่มีใครถือยศฝ่ายนั้น = "นักรบนิรนาม")
- [ ] โค่นแชมเปี้ยน → ทอง ×2 EXP ×1.5 + ข้อความเกียรติยศ + สกอร์สด + แต้มเข้า `!war`
- [ ] สู้แชมเปี้ยนหลายเทิร์นแล้วค่อยชนะ → ยังได้โบนัส/แต้มครบ (ธงข้ามเทิร์น)
- [ ] ตัวละครไม่มียศเผ่า → ไม่เจอแชมเปี้ยนเลย
- [ ] `!war` — สกอร์ถูกต้อง + บอกสถานะธีม / `!settheme auto` แล้วธีมอื่น `!war` ขึ้นข้อความรอธีม

## 6.8 กิลด์ P6 (2026-07-27)
- [ ] `!guild create ทดสอบ` (set_cash ให้พอก่อน) → หักเงินสด 3B + ยศ "ทดสอบ" โผล่ + **ห้องเสียงส่วนตัว** ใต้หมวดหมู่ ⌈🏛⌋ ห้องกิลด์ส่วนตัว ที่มีอยู่แล้ว (คนนอกมองไม่เห็น) + ลองชื่อมีเว้นวรรค + **ยศกิลด์ต้องเรียงใต้ยศคั่น ╔══❖═══ยศกิลด์═══❖══╗** (ยศบอทต้องอยู่สูงกว่ายศคั่น!)
- [ ] `!guild invite @คน` → เป้าหมายกดยืนยัน → ได้ยศ + เข้าเห็นห้องกิลด์
- [ ] คนนอก/สมาชิกธรรมดาใช้ invite/kick/withdraw/pay → โดนปฏิเสธทุกตัว
- [ ] `!guild deposit` (หักธนาคารผู้ฝาก) → `!guild bank` ยอดถูก → หัวหน้า `withdraw`/`pay @สมาชิก` ยอดวิ่งถูกฝั่ง + ถอนเกินคลังโดนกัน
- [ ] `!guild leave` สมาชิกออก (ยศหลุด) / หัวหน้า leave ไม่ได้ ต้อง disband
- [ ] `!guild disband` → ยศ+ห้องหาย + คลังคืนธนาคารหัวหน้า + สร้างชื่อเดิมซ้ำได้

## 6.9 กิลด์วอร์ P7 (2026-07-27) — ต้องมี 2 กิลด์ก่อน
- [ ] `!warguild @หัวหน้ากิลด์อื่น 1000` → อีกฝ่ายกดรับ → หักคลังทั้งสองฝ่าย + ห้องรบ ⚔️ โผล่ (เห็นเฉพาะ 2 กิลด์)
- [ ] `!fight` ในห้องรบ: เจอครบ 4 ชนิด (ทหาร/หัวหน้าชื่อจริง/ป้อม/ปราสาท) + สกอร์สดถูก + คูลดาวน์ 10 วิ
- [ ] คนนอกกิลด์คู่ศึก `!fight` → โดนปฏิเสธ / `!fight` นอกห้องรบ → เงียบ
- [ ] ปล่อยห้องเงียบ 1 นาที → ศึกจบเอง + **ประกาศผลที่ห้องที่ใช้คำสั่งท้าศึก** + ห้องรบลบตัวเอง (ลองทั้งเคสหมดเวลา 30 นาทีด้วย)
- [ ] ผู้ชนะได้กองกลาง 2×เดิมพันเข้าคลัง (`!guild bank` เช็ค) / เสมอ = คืนเดิมพัน
- [ ] ปิดบอทกลางศึก → เปิดใหม่ → เดิมพันถูกคืนทั้งสองกิลด์อัตโนมัติ

## 7. ความทนทานระบบ
- [ ] เล่นต่อเนื่อง 30+ ก้าวรวด — ไม่มี interaction timeout / ปุ่มค้าง
- [ ] ตายจากพิษกลางทาง → ปุ่ม respawn ทำงาน กลับหมู่บ้านถูกต้อง
- [ ] ไฟล์ backup รายวันถูกสร้าง (เช็คโฟลเดอร์ backup หลังเที่ยงคืน หรือเรียก manual)
- [ ] ผู้เล่น 2 คนเล่นพร้อมกัน — สถานะ/ทวีป/กระเป๋าไม่ปนกัน
