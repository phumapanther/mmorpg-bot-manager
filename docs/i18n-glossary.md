# อภิธานศัพท์แปลภาษา — Fragment Rift

## กฎการแปล

- **อังกฤษ** — ภาษาเกมสั้น กระชับ · ประโยคใช้ตัวพิมพ์ใหญ่แค่ตัวแรก · ปุ่มใช้คำกริยาสั้น ๆ
- **จีน** — **ตัวย่อ (简体)** · เครื่องหมายเต็มความกว้าง ，。！？：（）· ไม่เว้นวรรคระหว่างอักษรจีนกับตัวเลข
- **ญี่ปุ่น** — ประโยคใช้ です/ます · ปุ่ม/หัวข้อใช้คำนามหรือกริยาสั้น
- **คงไว้เป๊ะ:** emoji (ตำแหน่งเดิม) · ตัวเลข · `{ตัวแปร}` · แท็ก HTML ทั้งแท็กพร้อมแอตทริบิวต์ · คำสั่ง `!xxx` · `Fragment Rift` `WOLD Arture` `Discord` `PromptPay` · ปุ่มคีย์บอร์ด (`E`, `Space`)
- ชื่อในเกมที่มาจากเซิร์ฟเวอร์ (ชื่อทวีป/มอน/ไอเทม) **ยังไม่แปลในก้อน 1** — ข้อความรอบ ๆ แปลได้ตามปกติ
