เปิด DevTools → Console ค้างไว้ตลอด

## 🔴 สำคัญที่สุด — คีย์ HTML ตรงกับเบราว์เซอร์จริงไหม

ทำครบทั้ง **en · zh · ja** ทุกหน้า: `/` `/news` `/game` `/play` `/wold` `/topup` `/login` `/me`

- [ ] Console **ไม่มี** `[i18n] ไม่มีคำแปล:` ตอนโหลดหน้า
      (มี = คีย์ที่สคริปต์ดึงไม่ตรงกับที่เบราว์เซอร์อ่านกลับ → คัดลอกข้อความนั้นมาแจ้ง)
      ⚠️ หน้า `/play` ข้อความจาก `play.js` ยังเป็นไทย และ**ไม่ได้**ขึ้นเตือนเพราะยังไม่ห่อ `tr()` — ปกติ (ก้อน 2)

## ปุ่มเลือกภาษา
- [ ] อยู่ท้ายแถบเมนู · โชว์ภาษาที่ใช้อยู่
- [ ] เปลี่ยนแล้วหน้ารีโหลดเป็นภาษานั้นทันที
- [ ] ไปหน้าอื่นแล้วยังเป็นภาษาเดิม (คุกกี้ `lang`)
- [ ] ลบคุกกี้ แล้วตั้งภาษาเบราว์เซอร์เป็นญี่ปุ่น → เปิดเว็บครั้งแรกเป็นญี่ปุ่นเอง
- [ ] จอมือถือ (DevTools 375px): กางเมนูแล้วปุ่มเลือกภาษาอยู่ในคอลัมน์ ไม่ล้นจอ

## หน้าตา
- [ ] ภาษาไทย: ทุกหน้าหน้าตา**เหมือนก่อนแก้ทุกจุด** (ไม่มีอะไรขยับ)
- [ ] จีน/ญี่ปุ่น: ตัวอักษรไม่เป็นกล่อง □ · คันจิในหน้าญี่ปุ่นไม่ใช่ทรงจีน
- [ ] อังกฤษ/ญี่ปุ่นข้อความยาวกว่าไทย: ปุ่มในหน้า `/play` ไม่ล้น/ไม่ตกบรรทัดจนเละ (จด id ปุ่มที่ล้นไว้)
- [ ] `/me` `/topup`: ตัวเลขทอง/สลิป/QR ยังขึ้นถูกที่ (แท็ก `id` รอดหลังแปล)
