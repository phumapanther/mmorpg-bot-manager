## 🔴 ด่วนที่สุด — คำสั่งที่อาจเงียบแบบ `!login`

เพิ่งเจอบั๊ก path ชี้ผิดหลังย้ายไฟล์ **ลองคำสั่งพวกนี้ดูว่าตอบไหม**
(ถ้าพิมพ์แล้วเงียบสนิท = อาการเดียวกัน แจ้งได้เลย)

- [ ] `!login` — ต้องได้ปุ่มเข้าเว็บ ✅ (เทสแล้วใช้ได้)
- [ ] `!web` — ต้องได้ลิงก์เว็บ
- [ ] `!slip` (แนบรูป) — ต้องรับสลิปได้
- [ ] `!bag` `!bank` `!profile` — คำสั่งพื้นฐาน
- [ ] `!shop` `!craft` — ของที่ย้ายไป `core/services/`
- [ ] `!codex` — ที่แยกข้อมูลออกจาก embed
- [ ] คำสั่งแอดมิน 1-2 ตัว (ย้ายไป `bot_admin/`)

## 🎴 UNO — ของใหม่ทั้งหมด

### โหมดบอท (เล่นคนเดียวได้)
- [ ] คาสิโน → 🃏 ศึกไพ่รูน → **เจอหน้าเลือกโหมดก่อน** (ไม่โดดเข้าเกมทันที)
- [ ] กด 🤖 เล่นกับบอท → เข้าเกมได้ เล่นจนจบได้
- [ ] ไพ่ที่ลงได้เรืองแสง · กดกองจั่วได้ · ปุ่ม ? อธิบายไพ่

### โหมดเดิมพัน — **ต้องมี 2 คน 2 เบราว์เซอร์**
- [ ] กด 👥 เล่นกับเพื่อน → ตั้งเดิมพัน → **สร้างโต๊ะได้ ได้รหัสห้อง**
- [ ] คนที่ 2 กรอกรหัส → เข้าห้องได้ เห็นชื่อกันทั้งคู่
- [ ] **เงินถูกหักตอนเข้าโต๊ะ** (เช็ค `!profile` ก่อน/หลัง)
- [ ] เจ้าของห้องกดเริ่ม → แจกไพ่ทั้งคู่
- [ ] **ลงไพ่ได้จริง · อีกฝ่ายเห็นภายใน ~2 วิ** (ตรงนี้ยังไม่เคยเทสจริง)
- [ ] ยังไม่ถึงตาตัวเอง → ลงไพ่ไม่ได้
- [ ] **เล่นจนจบ → ผู้ชนะได้กองกลาง** (เช็คยอดทองทั้งสองคน รวมกันต้องเท่าเดิม)
- [ ] ออกกลางเกม → **ไม่ได้เงินคืน** · ยุบก่อนเริ่ม → **คืนครบ**

### ชวนเพื่อนผ่าน DM
- [ ] ในห้อง → เห็นรายชื่อเพื่อน → กด "ชวน"
- [ ] **บอททัก DM เพื่อน** พร้อมปุ่ม ✅ เข้าร่วม
- [ ] เพื่อนกดปุ่ม → ได้รหัสห้อง เข้าได้
- [ ] คนอื่นกดปุ่มคำเชิญของเราไม่ได้
- [ ] ชวนคนที่ไม่ใช่เพื่อน → ต้องไม่ได้
