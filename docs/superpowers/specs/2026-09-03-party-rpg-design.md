## เป้าหมาย

โหมดใหม่ในหมวด "ออกผจญภัย" ปุ่มอยู่**ถัดจาก "เริ่มออกเดินทาง"** ชื่อ **"ชวนเพื่อนเดินทาง"**

เหมือนผจญภัยเดิม (สุ่มเหตุการณ์) แต่:
- ชวนเพื่อนเข้าปาร์ตี้ **สูงสุด 5 คน**
- ต่อสู้แบบ **เทิร์นเบส** — สลับกันเลือกคำสั่ง เลือกเป้าหมาย
- ใช้**ดาต้าผู้เล่นเดิมทั้งหมด** (ชุด · อาวุธ · แฟชั่น · สัตว์เลี้ยง · ธาตุ · สกิลอาชีพ)
- เหมือน "เวอร์ชันรีมาสเตอร์" ของเกมหลัก

## สถาปัตยกรรม

### หัวใจ: แยก "เกิดอะไรขึ้น" ออกจาก "วาดยังไง"

นี่คือสิ่งที่ทำให้**เปลี่ยนกราฟิกได้ง่าย** ตามที่เจ้าของเกมสั่ง

```
bot/games/party/              🔵 แกน — Python ล้วน ไม่รู้จักการวาด
├── __init__.py
├── rules.py       กติกาล้วน ๆ (ใครตีใครได้ · ธาตุข่มกัน)
├── engine.py      คิวเทิร์น · สถานะสมรภูมิ
├── combat.py      ดาเมจ · ธาตุ · AoE · คริติคอล
├── monsters.py    มอน + บอสหลายเฟส
├── rewards.py     แบ่งทอง · สุ่มดรอป
├── bot_ai.py      บอทเล่นแทนคนที่หลุด
└── room.py        ปาร์ตี้บนล็อบบี้กลาง

license_server/web_static/games/party/    🔴 ภาพ — เปลี่ยนได้อิสระ
├── renderer_basic.js     เฟส 1 — Canvas 2D เรียบ ๆ
├── renderer_pixel.js     เฟส 2 — สวยขึ้น (ยังไม่ทำ)
└── ...                   ใครจะเพิ่มแบบไหนก็ได้
```

### สัญญาระหว่างแกนกับภาพ: เซิร์ฟเวอร์ส่ง "เหตุการณ์" ไม่ส่งภาพ

```json
{"t": "turn_start", "who": "p1"}
{"t": "dice",   "who": "p1", "rolls": [17, 4], "total": 21}
{"t": "attack", "from": "p1", "to": "m2", "dmg": 120, "element": "fire", "crit": true}
{"t": "aoe",    "from": "p3", "targets": ["m1","m2","m3"], "dmg": [40,35,52]}
{"t": "heal",   "from": "p2", "to": "p4", "amount": 80}
{"t": "die",    "who": "m2"}
{"t": "phase",  "who": "boss", "phase": "rage"}
```

**เปลี่ยนกราฟิก = เขียนไฟล์ renderer ใหม่ แกนไม่ต้องแตะเลย**
→ ทีมกราฟิกกับทีมกติกาทำงานคู่ขนานได้ ไม่ชนกัน

### สัญญาการเสียบเกม (ต้องเพิ่มในเทมเพลต)

| แบบ | ใช้เมื่อ | ข้อดี |
|---|---|---|
| `inline` | Canvas 2D (เฟส 1 ใช้แบบนี้) | เบา ใช้ตัวช่วยกลางร่วมได้ |
| `iframe` | Phaser · Pygbag · เอนจินหนัก | แยกขาด 100% · โหลดเฉพาะตอนกดเข้าเกม |

**ทำไมต้องมี iframe**: เจ้าของเกมให้อิสระเรื่องเอนจิน
วัดแล้ว **Pygbag ต้องโหลด runtime 12 MB จาก CDN ภายนอก** (`pygame-web.github.io`)
ถ้าเสียบแบบ inline จะกระทบทุกคนที่เปิดหน้าเว็บ — iframe ทำให้โหลดเฉพาะคนที่กดเข้าเกมนั้น

## กติกาการเล่น

### ลำดับเทิร์น — ทอยครั้งเดียวตอนเริ่ม

```
ความไว = level + โบนัสอาชีพ + เต๋า(1-20)
เรียงมาก→น้อย = คิวคงที่ทั้งรอบ
```

โชว์แถบคิวล่วงหน้า: `🗡️คุณ → 👹มอนA → 🏹บี → 👑บอส → 🛡️ซี`

**ทำไมไม่ทอยใหม่ทุกรอบ**: ผู้เล่นต้องวางแผนได้ว่า "อีก 2 ตาถึงเรา เก็บสกิลไว้ใช้ตอนนั้น"
ทอยใหม่ทุกรอบ = วางแผนไม่ได้เลย

### สถานะระหว่างเล่น

| อยู่ตาไหน | เห็นอะไร |
|---|---|
| ตาเรา | ปุ่มคำสั่ง 5 อย่าง + เลือกเป้า + นับถอยหลัง 60 วิ |
| ตาคนอื่น | ดูอย่างเดียว เห็น `⏳ บี กำลังเลือก...` |
| ตามอน | ดูอนิเมชัน |
| ตายแล้ว | ดูอย่างเดียว รอเพื่อนชุบ |

### คำสั่ง 5 อย่าง

`⚔️ โจมตี` · `✨ สกิล` · `🎒 ไอเทม` · `🛡️ ป้องกัน` · `🏃 หนี`

**การเล็งเป้า** — สกิลบอกเองว่าเล็งแบบไหน:
`single` (ตัวเดียว) · `all` (AoE ทุกตัว) · `ally` (ฮีล/ชุบเพื่อน) · `self` (บัฟตัวเอง)

### มอนสเตอร์

ใช้**ดาต้ามอนจากเกมหลัก** (`monster_ranks` ใน Panel + `game_data.py`) ไม่สร้างใหม่

```
ปาร์ตี้ปกติ  →  มอน 3-5 ตัว (ผสมแรงค์ตามระดับปาร์ตี้)
บอสเรด      →  บอส 1 + ลูกน้อง 2-4
```

### บอสหลายเฟส

| HP | เฟส |
|---|---|
| 100-70% | ปกติ |
| 70-30% | 🔥 คลั่ง — ดาเมจขึ้น มีท่า AoE |
| 30-0% | 💀 สิ้นหวัง — เรียกลูกน้อง / ท่าไม้ตาย |

**เตือนล่วงหน้า 1 เทิร์นเสมอ** ("กำลังสะสมพลัง!") ให้ปาร์ตี้เลือกได้ว่าจะป้องกันหรือรีบเบิร์น
ไม่งั้นตายแบบงง ๆ ไม่สนุก

### รางวัล

**ทอง**: รวมทั้งปาร์ตี้ = **1.5 เท่าของเล่นเดี่ยว แล้วหารกัน**
→ ชวนเพื่อนคุ้มกว่านิดหน่อย แต่ไม่ทำเงินเฟ้อ (แก้ทีหลังยากมาก)

**ไอเทม**: ดรอปแล้ว**สุ่มว่าใครได้** — อยากแบ่งกันใช้ `!give` ที่มีอยู่แล้ว
(ยืนยันแล้ว: `bot/apps/bot_game/player_commands.py:782`)

**ตัวเลขทั้งหมดตั้งได้ใน Panel** ไม่ต้องแก้โค้ด
