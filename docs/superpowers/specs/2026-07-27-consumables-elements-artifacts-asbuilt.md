## 3. ธาตุผู้เล่น & Dual-Race

### 3.1 ตารางเผ่า → ธาตุ (`RACE_ELEMENTS`, keyword match กับชื่อยศ)
- ผู้เล่น: มนุษย์ แสง+ลม / เอลฟ์ ไม้ / ยักษ์ ดิน / คนแคระ ดิน+ไฟ / มังกร ไฟ / ภูติ ลม / เงือก น้ำ / มิ้ง ลม
- มอนสเตอร์: Dragon ไฟ / Unicon แสง / Slime น้ำ / Ogre+Orc ดิน / Goblins ไม้ / Lich+Skeleton+Zombie มืด

### 3.2 ตารางข่ม (`ELEMENT_ADVANTAGE` / `ELEMENT_RESIST`)
- ตีแรง ×1.5: ไฟ→ไม้, น้ำ→ไฟ, ดิน→น้ำ, ไม้→ดิน, ลม→ดิน, แสง↔มืด (สาดใส่กันทั้งคู่)
- รับเบา ×0.75: ไฟ←น้ำ, น้ำ←ดิน, ดิน←ไม้, ไม้←ไฟ, ลม←ไฟ
- ฝั่งรับ แสง↔มืด: โดนหนักขึ้น ×1.5

### 3.3 หลายยศ / Dual-Race
- ถือหลายยศเผ่า = ได้หลายธาตุพร้อมกัน (array, ลำดับเสถียร, ไม่ซ้ำ)
- ข่มซ้อน: สองธาตุข่มเป้าเดียวกัน = ×2.0 (cap), หนึ่งธาตุ = ×1.5
- **[ยังไม่ทำ — แผนงานเฟสถัดไป]** Passive Skill Synergy ฝั่งผู้เล่น (เช่น ไฟโบนัสดาเมจ, น้ำดูดเลือด) — ปัจจุบัน passive ธาตุเป็นของฝั่งมอนเท่านั้น ธาตุผู้เล่นมีผลเฉพาะตัวคูณข่ม/ต้านทาน

## 4. Artifact ช่องเดียว

กติกาหลัก: ผู้เล่นมี **1 ช่อง** — สวมชิ้นใหม่ทับ = ชิ้นเก่า**ถูกทำลายถาวร** (implement เป็นสถานะ
`artifact: True, no_tick: True` ใน STATUS_EFFECTS, ไอเทม id 42-51 effect `equip_artifact`)

| ชิ้น | ผลที่ implement จริง |
