# แผนงาน: ยกเกม Fragment Rift ขึ้นเล่นบนเว็บ

> เริ่ม 2026-08-13 · งานยาว ทำทีละขั้น **ขออนุมัติทุกขั้นก่อนลงมือ** · ทุกขั้นจบด้วย commit เป็นจุด backup

## หลักการเหล็ก 4 ข้อ (ห้ามละเมิด)

1. **logic อยู่ที่ Python ที่เดียว** — เว็บส่งแค่ "กดปุ่มไหน" เซิร์ฟเวอร์รันฟังก์ชันชุดเดียวกับที่บอท
   Discord เรียก แล้วส่งผลกลับมาให้ JS วาด · ห้ามมีกฎเกมซ้ำในเบราว์เซอร์แม้แต่บรรทัดเดียว
2. **แยกตรรกะออกจาก Discord ก่อนเสมอ** — เจอโค้ดเกมที่ผูกกับ `interaction`/`View` ให้ดึงออกเป็น
   ฟังก์ชันล้วนก่อน แล้วให้ทั้ง Discord และเว็บเรียกตัวเดียวกัน (แพทเทิร์นเดียวกับ `bank_action()`)
3. **Discord ต้องทำงานเหมือนเดิมเป๊ะ** — ทุกขั้นที่รื้อโค้ดเดิม ต้องมีเทสยืนยันว่าพฤติกรรมฝั่งบอทไม่เปลี่ยน
4. **สองแพลตฟอร์มพร้อมกัน** — เว็บ**ไม่ได้มาแทน**ดิส แต่เล่นควบคู่กัน ไอดีเดียว ข้อมูลชุดเดียว
   สลับไปมาได้ทุกเมื่อ · ทำอะไรบนเว็บต้องเห็นผลในดิสทันทีและกลับกัน

### กติกาสองแพลตฟอร์ม (ต้องตัดสินก่อนเฟส 5)

ผู้เล่นมีคอลัมน์ `current_state` อยู่แล้ว (`idle`/`fighting`/`village`/`trap_defense`...)
ถ้ากำลังสู้มอนอยู่ในดิสแล้วเปิดเว็บ ต้องไม่เกิด "สู้ 2 หน้าจอพร้อมกัน" เพราะจะได้รางวัลซ้ำ

**กติกา:** เกมมีสถานะเดียวต่อไอดี — ฝั่งไหนก็ตามที่เปิดอยู่จะเห็นสถานะเดียวกัน
เช่นกำลังสู้ในดิส เปิดเว็บก็เจอหน้าไฟต์ตัวเดิม HP เดิม กดสู้ต่อจากเว็บได้เลย
(ธนาคาร/ร้านค้า/กระเป๋า ไม่มีปัญหานี้ เพราะเป็นการกระทำครั้งเดียวจบ)

## เฟส 8 — กระดานทอยเต๋ารับของรายวัน (ของใหม่ทั้งหมด)

อ้างอิงภาพที่ผู้ใช้ส่ง (แนวเดียวกับ "การผจญภัยของภูตดำ")

**กติกาที่ตกลงแล้ว:**
- ทอยได้ **3 ครั้ง/วัน** เท่านั้น (ไม่มีคูลดาวน์ ไม่มีทอยเพิ่ม) รีเซ็ตเที่ยงคืน
- เดินวนกระดานเหมือนในภาพ ตกช่องไหนได้ของช่องนั้น **ครบรอบได้รางวัลใหญ่**
- **กระดานเปลี่ยนหน้าตา/ของรางวัลตามธีมอีเวนต์สัปดาห์** (เกาะระบบ `get_weekly_theme()` เดิม)
- รางวัล: ทองจำนวนน้อย · EXP · บัฟชั่วคราว (พรบรรพชน/เข็มทิศ) · ไอเทมที่มีอยู่แล้ว (ยาฮีล/ใบซ่อม/วัสดุ)

| ขั้น | ทำอะไร |
|---|---|
| 8.1 | `bot/dice_board.py` — นิยามกระดานต่อธีม, ทอย, เดิน, จ่ายรางวัล, นับโควตา 3 ครั้ง/วัน |
| 8.2 | ตารางเก็บตำแหน่งหมาก + จำนวนทอยที่เหลือรายวัน |
| 8.3 | คำสั่ง/ปุ่มในดิส (เล่นได้ทั้งสองแพลตฟอร์ม โควตาใช้ร่วมกัน) |
| 8.4 | API + หน้าเว็บ + **อนิเมชันเต๋ากลิ้ง หมากกระโดดทีละช่อง ช่องเรืองแสงตอนตก การ์ดรางวัลเด้ง** |

**จุดต้องระวัง:** เป็นทางเข้าเงิน/ไอเทมใหม่เข้าเศรษฐกิจ ต้องคุมปริมาณให้เล็ก (ของจิปาถะ)
และเทสกันยิงซ้ำให้แน่น (กดรัว = ได้ของเกินโควตา)
