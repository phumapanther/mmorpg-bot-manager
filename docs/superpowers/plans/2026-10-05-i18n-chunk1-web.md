## Global Constraints

- ชื่อฟังก์ชันแปลคือ **`tr`** ทั้ง Python และ JS — ห้ามใช้ `_` หรือ `t` (ชนตัวแปรเดิม 53 + 26 จุด)
- `tr()` รับ**ข้อความตรง ๆ** (string literal) เป็นตัวแรกเสมอ · ตัวแปรเขียน `{ชื่อ}` ชื่อเป็นอักษรอังกฤษ/ตัวเลข/`_` · ห้าม f-string / template `${}` ในคีย์
- ภาษา: `th` `en` `zh` `ja` · `zh` = จีนตัวย่อ (简体) · รหัสว่าง → `th` · ภาษาอื่นที่ไม่รู้จัก → `en`
- ไฟล์คำแปล: `license_server/web_static/locales/{en,zh,ja}.json` · **ไม่มี `th.json`** · เขียนด้วย `json.dumps(d, ensure_ascii=False, indent=1, sort_keys=True) + "\n"`
- หาคำแปลไม่เจอ / ค่าว่าง / ไฟล์หาย → แสดงภาษาไทยเดิม **ห้าม throw**
- `admin.html` **ไม่แปลเนื้อหา** (แต่ต้องโหลด `i18n.js` เพราะ `web.js` เรียก `tr()`)
- ไม่แปล: ข้อความจาก Panel/ข่าวที่แอดมินพิมพ์ · ชื่อยศดิสคอร์ด · คำสั่ง `!xxx` · URL/`href`/`id`/`class` · ชื่อเฉพาะ `Fragment Rift` `WOLD Arture` `Discord` `PromptPay`
- ข้อความจากเซิร์ฟเวอร์ (`data.detail`, ผลจาก API) และข้อความใน `play.js` `uno.js` `worms.js` `scene.js` `games/**` **ยังไม่แตะ** — เป็นงานก้อน 2
- รันเทสจากรากโปรเจ็คเสมอ: `python -m pytest ...` (เทสอ่านไฟล์ด้วย path สัมพัทธ์)
- ชื่อเทส/ข้อความ assert/คอมเมนต์เป็นภาษาไทยตามสไตล์เดิมของโปรเจ็ค
- commit: `feat(i18n): ...` ภาษาไทย ปิดท้ายด้วย `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

```python
"""🌐 แปลภาษา — ข้อความไทยคือคีย์ · ภาษาปัจจุบันอยู่ใน contextvar

    from bot.i18n import tr
    await ctx.send(tr("ได้รับ {gold} ทอง", gold=g))

- หาคำแปลไม่เจอ / ไฟล์ไม่มี (exe ลูกค้า) → คืนข้อความไทยเดิม ไม่มีวันพัง
- ชื่อ tr ไม่ใช่ _ เพราะโค้ดเดิมใช้ _ เป็นตัวแปรทิ้งอยู่ 53 จุด (for _ in ...)
- คู่กับ license_server/web_static/i18n.js ฝั่งเบราว์เซอร์ — ไฟล์คำแปลชุดเดียวกัน
สเปก: docs/superpowers/specs/2026-10-05-i18n-design.md
"""
import contextlib
import contextvars
import json
from pathlib import Path

LANGS = ("th", "en", "zh", "ja")
# แบบเดียวกับ bot/event_images.py — อิง __file__ จึงใช้ได้ทั้งรันจากซอร์ส, Docker และ exe
LOCALES_DIR = Path(__file__).resolve().parent.parent / "license_server" / "web_static" / "locales"

_lang = contextvars.ContextVar("lang", default="th")
_tables = {}


def normalize(code):
    """รหัสภาษาดิสคอร์ด/เบราว์เซอร์ → th/en/zh/ja · ว่าง → th · ภาษาอื่น → en

    คู่กับ normLang() ใน web_static/i18n.js — tests/test_i18n_js.py เทียบให้ตรงกันเสมอ
    """
    base = str(code or "").strip().lower().replace("_", "-").split("-")[0]
    if not base:
        return "th"
    return base if base in LANGS else "en"


def current():
    """ภาษาของคำสั่ง/คำขอที่กำลังรันอยู่"""
    return _lang.get()


def set_lang(code):
    """ตั้งภาษาให้คำสั่ง/คำขอนี้ (task ที่สร้างต่อจากนี้ได้ภาษาเดียวกัน — asyncio คัดลอก context ให้)"""
    _lang.set(normalize(code))


@contextlib.contextmanager
def use_lang(code):
    """สลับภาษาชั่วคราว เช่นประกาศลงห้องด้วยภาษาเซิร์ฟเวอร์ — ออกจาก with แล้วกลับภาษาเดิม"""
    token = _lang.set(normalize(code))
    try:
        yield
    finally:
        _lang.reset(token)


def _table(lang):
    # ponytail: โหลดครั้งเดียวต่อโปรเซส — แก้ไฟล์คำแปลแล้วต้องรีสตาร์ทบอท/เว็บ
    if lang not in _tables:
        try:
            _tables[lang] = json.loads((LOCALES_DIR / f"{lang}.json").read_text(encoding="utf-8"))
        except (OSError, ValueError):
            _tables[lang] = {}          # exe ลูกค้าไม่มีโฟลเดอร์นี้ / ไฟล์พัง → ตกเป็นไทย
    return _tables[lang]


def tr(text, **kw):
    """ข้อความไทย → ภาษาปัจจุบัน แล้วเติม {ตัวแปร} · ไม่มีคำแปล = ไทยเดิม"""
    lang = _lang.get()
    s = text if lang == "th" else (_table(lang).get(text) or text)
    return s.format(**kw) if kw else s
```

```python
"""🌐 ดึงข้อความที่ต้องแปล + เช็คว่าแปลครบ

    python scripts/i18n_extract.py           รายงาน: ยังไม่แปล / คีย์ร้าง / ข้อความไทยที่ยังไม่ติดป้าย
    python scripts/i18n_extract.py --write   เติมคีย์ใหม่ (ค่าว่าง) ลง en/zh/ja.json ให้แปลต่อ

ข้อความไทยคือคีย์ · ที่มาของคีย์:
  .py   → tr("...")                       (bot/ core/ license_server/)
  .js   → tr("...")                       (web_static/**/*.js ยกเว้น i18n.js)
  .html → data-i18n / data-i18n-html / data-i18n-attr + tr("...") ใน <script> ของหน้า
เทส tests/test_i18n_*.py ใช้ฟังก์ชันในไฟล์นี้ตัดสิน — แก้กฎที่นี่ที่เดียว
สเปก: docs/superpowers/specs/2026-10-05-i18n-design.md
"""
import ast
import json
import re
import sys
from html.parser import HTMLParser
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
WEB = ROOT / "license_server" / "web_static"
LOCALES = WEB / "locales"
LANGS = ("en", "zh", "ja")
PY_DIRS = ("bot", "core", "license_server")
ADMIN_PAGES = {"admin.html"}                       # หน้าแอดมินไม่แปล (สเปกข้อ 5)
I18N_ATTRS = {"title", "placeholder", "alt", "aria-label", "content"}
VOID = {"area", "base", "br", "col", "embed", "hr", "img", "input",
        "link", "meta", "source", "track", "wbr"}
THAI = re.compile(r"[฀-๿]")
_TR_CALL = re.compile(r"\btr\(")


def norm(s):
    """ยุบช่องว่างทุกแบบเหลือช่องเดียว — ตรงกับ i18nKey() ใน i18n.js"""
    return re.sub(r"\s+", " ", s).strip()


# ── Python ────────────────────────────────────────────────────────────────

def keys_from_py(src, name="<py>"):
    """คืน (คีย์, ปัญหา) จาก tr("...") / i18n.tr("...") ในซอร์สไพทอน"""
    keys, problems = set(), []
    if not _TR_CALL.search(src):
        return keys, problems
    for node in ast.walk(ast.parse(src)):
        if not isinstance(node, ast.Call):
            continue
        f = node.func
        fname = f.id if isinstance(f, ast.Name) else f.attr if isinstance(f, ast.Attribute) else None
        if fname != "tr":
            continue
        a = node.args[0] if node.args else None
        if isinstance(a, ast.Constant) and isinstance(a.value, str):
            keys.add(a.value)
        else:
            problems.append(f"{name}:{node.lineno} tr() ต้องรับข้อความตรง ๆ ไม่ใช่ตัวแปร")
    return keys, problems


# ── JavaScript ────────────────────────────────────────────────────────────

_JS_STR = r'''"(?:[^"\\\n]|\\.)*"|'(?:[^'\\\n]|\\.)*'|`(?:[^`\\]|\\.)*`'''
_JS_TR = re.compile(r"\btr\(\s*(" + _JS_STR + ")?", re.S)
_JS_TR_LIT = re.compile(r"\btr\(\s*(?:" + _JS_STR + ")", re.S)
# คอมเมนต์ // ที่ไม่ได้ต่อจาก : (กัน https://) และ /* ... */
_JS_COMMENT = re.compile(r"/\*.*?\*/|(?<![:\\])//[^\n]*", re.S)


def _js_unescape(lit):
    body = lit[1:-1]
    return re.sub(r"\\(.)", lambda m: {"n": "\n", "t": "\t"}.get(m.group(1), m.group(1)), body, flags=re.S)


def keys_from_js(src, name="<js>", line0=1):
    """คืน (คีย์, ปัญหา) จาก tr("...") ในซอร์ส JS · line0 = เลขบรรทัดของบรรทัดแรกใน src"""
    keys, problems = set(), []
    for m in _JS_TR.finditer(src):
        line = line0 + src.count("\n", 0, m.start())
        lit = m.group(1)
        if not lit:
            problems.append(f"{name}:{line} tr() ต้องรับข้อความตรง ๆ ไม่ใช่ตัวแปร")
        elif lit.startswith("`") and "${" in lit:
            problems.append(f"{name}:{line} tr(`...${{}}`) ใช้ไม่ได้ — ใช้ {{ชื่อ}} + ตัวแปรแทน")
        else:
            keys.add(_js_unescape(lit))
    return keys, problems


def _blank(m):
    return "\n" * m.group(0).count("\n")          # ลบแต่คงเลขบรรทัดไว้


def bare_thai_js(src, name="<js>", line0=1):
    """ข้อความไทยที่ยังไม่ได้ห่อ tr() (ไม่นับคอมเมนต์)"""
    s = _JS_TR_LIT.sub(_blank, src)
    s = _JS_COMMENT.sub(_blank, s)
    out = []
    for i, line in enumerate(s.split("\n"), line0):
        if THAI.search(line):
            out.append(f"{name}:{i} ยังไม่ได้ห่อ tr(): {line.strip()[:80]}")
    return out


# ── HTML ──────────────────────────────────────────────────────────────────
# serialize แบบเดียวกับที่เบราว์เซอร์คืนจาก innerHTML — ไม่งั้นคีย์ไม่ตรง บล็อกนั้นไม่แปลเงียบ ๆ

def _esc_text(s):
    return s.replace("&", "&amp;").replace("\xa0", "&nbsp;").replace("<", "&lt;").replace(">", "&gt;")


def _esc_attr(s):
    return s.replace("&", "&amp;").replace("\xa0", "&nbsp;").replace('"', "&quot;")


def _start(tag, attrs):
    return "<" + tag + "".join(f' {k}="{_esc_attr(v or "")}"' for k, v in attrs) + ">"


class _Page(HTMLParser):
    """อ่านหน้า HTML: เก็บคีย์จากป้าย data-i18n* + จับข้อความไทยที่ยังไม่ติดป้าย"""

    def __init__(self, name):
        super().__init__(convert_charrefs=True)
        self.name = name
        self.keys, self.problems, self.scripts = set(), [], []
        self.stack = []          # แท็กที่เปิดอยู่
        self.region = None       # [โหมด "text"/"html", ความลึกของเจ้าของป้าย, ชิ้นส่วนที่เก็บ]
        self.raw = 0             # อยู่ใน <script>/<style> กี่ชั้น

    def _at(self):
        return f"{self.name}:{self.getpos()[0]}"

    def _attrs(self, tag, a):
        wanted = {x.strip() for x in (a.get("data-i18n-attr") or "").split(",") if x.strip()}
        for k in sorted(wanted):
            v = norm(a.get(k) or "")
            if v:
                self.keys.add(v)
            else:
                self.problems.append(f"{self._at()} data-i18n-attr บอก {k} แต่ไม่มีค่า")
        for k in sorted(I18N_ATTRS - wanted):
            if THAI.search(a.get(k) or ""):
                self.problems.append(f"{self._at()} <{tag} {k}> เป็นไทยแต่ไม่ได้ใส่ใน data-i18n-attr")

    def handle_starttag(self, tag, attrs):
        a = dict(attrs)
        self._attrs(tag, a)
        r = self.region
        if r:
            if r[0] == "text":
                self.problems.append(f"{self._at()} data-i18n มีแท็ก <{tag}> ข้างใน — ใช้ data-i18n-html")
            elif "data-i18n" in a or "data-i18n-html" in a:
                self.problems.append(f"{self._at()} ห้ามซ้อน data-i18n ใน data-i18n-html")
            r[2].append(_start(tag, attrs))
        if tag in VOID:
            return
        self.stack.append(tag)
        if tag in ("script", "style"):
            self.raw += 1
        if not r and ("data-i18n" in a or "data-i18n-html" in a):
            self.region = ["html" if "data-i18n-html" in a else "text", len(self.stack), []]

    def handle_endtag(self, tag):
        if tag in VOID or tag not in self.stack:
            return
        while self.stack:
            t = self.stack.pop()
            if t in ("script", "style"):
                self.raw -= 1
            r = self.region
            if r and len(self.stack) < r[1]:           # ปิดตัวเจ้าของป้ายแล้ว
                key = norm("".join(r[2]))
                if key:
                    self.keys.add(key)
                else:
                    self.problems.append(f"{self._at()} data-i18n ว่างเปล่า")
                self.region = None
            elif r and r[0] == "html":
                r[2].append(f"</{t}>")
            if t == tag:
                break

    def handle_data(self, data):
        if self.raw:
            if self.stack and self.stack[-1] == "script":
                self.scripts.append((self.getpos()[0], data))
            return
        r = self.region
        if r:
            r[2].append(data if r[0] == "text" else _esc_text(data))
        elif THAI.search(data):
            self.problems.append(f"{self._at()} ข้อความไทยยังไม่ได้ติดป้าย data-i18n: {norm(data)[:60]}")

    def handle_comment(self, data):
        if self.region and self.region[0] == "html":
            self.region[2].append(f"<!--{data}-->")


def scan_html(src, name="<html>"):
    """คืน (คีย์, ปัญหา) ของหน้า HTML — รวม tr() และไทยที่ยังไม่ห่อใน <script> ของหน้าด้วย"""
    p = _Page(name)
    p.feed(src)
    p.close()
    keys, problems = set(p.keys), list(p.problems)
    for line0, js in p.scripts:
        k, pr = keys_from_js(js, name, line0)
        keys |= k
        problems += pr + bare_thai_js(js, name, line0)
    return keys, problems


# ── ทั้งโปรเจ็ค ────────────────────────────────────────────────────────────

def player_pages():
    return sorted(p for p in WEB.glob("*.html") if p.name not in ADMIN_PAGES)


def collect():
    """คืน (คีย์ทั้งหมด, tr() ที่ใช้ผิด) — ปัญหาติดป้ายในหน้าดูได้จาก scan_html ทีละหน้า"""
    keys, problems = set(), []
    for d in PY_DIRS:
        for f in sorted((ROOT / d).rglob("*.py")):
            if "__pycache__" in f.parts:
                continue
            k, p = keys_from_py(f.read_text(encoding="utf-8"), f.relative_to(ROOT).as_posix())
            keys |= k
            problems += p
    for f in sorted(WEB.rglob("*.js")):
        if f.name == "i18n.js":
            continue
        k, p = keys_from_js(f.read_text(encoding="utf-8"), f.relative_to(ROOT).as_posix())
        keys |= k
        problems += p
    for f in player_pages():
        keys |= scan_html(f.read_text(encoding="utf-8"), f.relative_to(ROOT).as_posix())[0]
    return keys, problems


def load(lang):
    f = LOCALES / f"{lang}.json"
    return json.loads(f.read_text(encoding="utf-8")) if f.exists() else {}


def save(lang, table):
    (LOCALES / f"{lang}.json").write_text(
        json.dumps(table, ensure_ascii=False, indent=1, sort_keys=True) + "\n", encoding="utf-8")


def main(argv):
    keys, problems = collect()
    for f in player_pages():
        problems += scan_html(f.read_text(encoding="utf-8"), f.relative_to(ROOT).as_posix())[1]
    print(f"🔑 คีย์ทั้งหมด {len(keys)}")
    for lang in LANGS:
        table = load(lang)
        missing = sorted(k for k in keys if not table.get(k))
        unused = sorted(set(table) - keys)
        print(f"[{lang}] ยังไม่แปล {len(missing)} · คีย์ร้าง {len(unused)}")
        for k in unused:
            print(f"   ร้าง: {k[:70]}")
        if "--write" in argv:
            for k in missing:
                table.setdefault(k, "")
            save(lang, table)
```

```js
// 🌐 แปลภาษาหน้าเว็บ — ข้อความไทยคือคีย์ · คู่กับ bot/i18n.py (ไฟล์คำแปลชุดเดียวกัน)
// ต้องโหลด "ก่อน" web.js ทุกหน้า (tests/test_i18n_js.py เช็ค) แล้วมันจะแปลป้ายในหน้าให้ทันที:
//   tr("ได้รับ {gold} ทอง", { gold: 5 })        แปล + เติมตัวแปร (ตัวแรกต้องเป็นข้อความตรง ๆ)
//   <p data-i18n>ข้อความล้วน</p>                 แปล textContent
//   <p data-i18n-html>มี <b id="x"></b> แท็ก</p>  แปล innerHTML (คำแปลต้องมีแท็ก/id ครบ)
//   <input placeholder="..." data-i18n-attr="placeholder,title">
// ชื่อ tr ไม่ใช่ t — โค้ดเดิมใช้ t เป็นตัวแปร local อยู่ 26 จุด
// สเปก: docs/superpowers/specs/2026-10-05-i18n-design.md

const I18N_LANGS = ["th", "en", "zh", "ja"];
// ชื่อภาษาเขียนด้วยภาษาตัวเองเสมอ — คนอ่านไทยไม่ออกก็หาภาษาตัวเองในปุ่มเลือกเจอ
const I18N_NAMES = { th: "ไทย", en: "English", zh: "中文", ja: "日本語" };

/** รหัสภาษาเบราว์เซอร์/คุกกี้ → th/en/zh/ja · ว่าง → th · ภาษาอื่น → en (คู่กับ normalize() ใน bot/i18n.py) */
function normLang(code) {
  const base = String(code || "").trim().toLowerCase().replace(/_/g, "-").split("-")[0];
  if (!base) return "th";
  return I18N_LANGS.includes(base) ? base : "en";
}

/** คุกกี้ lang ก่อน → ภาษาเบราว์เซอร์ → ไทย */
function pickLang() {
  const ck = (typeof document !== "undefined" && document.cookie) || "";
  const m = ck.match(/(?:^|;\s*)lang=([^;]*)/);
  if (m) return normLang(decodeURIComponent(m[1]));
  const nav = typeof navigator !== "undefined" && navigator
    ? ((navigator.languages && navigator.languages[0]) || navigator.language) : "";
  return normLang(nav);
}

const I18N_LANG = pickLang();
let I18N_DICT = {};
if (I18N_LANG !== "th" && typeof XMLHttpRequest !== "undefined") {
  // ponytail: XHR แบบ sync = บล็อกหน้าเท่า <script src> ธรรมดา (คอนโซลเตือน deprecated)
  // แลกกับ tr() พร้อมใช้ก่อน web.js/play.js รัน ไม่ต้องรื้อทุกหน้าให้รอ promise
  // ถ้าเบราว์เซอร์เลิกรองรับ → ทำ route /locales/<lang>.js ฝั่งเซิร์ฟเวอร์แล้วโหลดด้วย <script>
  try {
    const x = new XMLHttpRequest();
    x.open("GET", "/locales/" + I18N_LANG + ".json", false);
    x.send();
    if (x.status === 200) I18N_DICT = JSON.parse(x.responseText);
  } catch (e) { /* เน็ตสะดุด/ไฟล์พัง → แสดงไทยไปก่อน */ }
}

const _i18nMissing = new Set();

/** ข้อความไทย → ภาษาที่เลือก แล้วเติม {ตัวแปร} · ไม่มีคำแปล = ไทยเดิม (เตือนในคอนโซลครั้งเดียว) */
function tr(text, vars) {
  let s = text;
  if (I18N_LANG !== "th") {
    if (Object.hasOwn(I18N_DICT, text) && I18N_DICT[text]) s = I18N_DICT[text];
    else if (!_i18nMissing.has(text)) { _i18nMissing.add(text); console.warn("[i18n] ไม่มีคำแปล:", text); }
  }
  return vars ? s.replace(/\{(\w+)\}/g, (m, k) => (k in vars ? vars[k] : m)) : s;
}

/** คีย์ของข้อความ/HTML/แอตทริบิวต์ในหน้า = ยุบช่องว่างก่อน (คู่กับ norm() ใน scripts/i18n_extract.py) */
function i18nKey(s) { return String(s).replace(/\s+/g, " ").trim(); }

/** แปลทุก [data-i18n*] ใต้ root — ไฟล์นี้เรียกให้ทั้งหน้าเองตอนโหลด */
function applyI18n(root) {
  if (I18N_LANG === "th" || !root || !root.querySelectorAll) return;
  root.querySelectorAll("[data-i18n]").forEach((el) => { el.textContent = tr(i18nKey(el.textContent)); });
  root.querySelectorAll("[data-i18n-html]").forEach((el) => { el.innerHTML = tr(i18nKey(el.innerHTML)); });
  root.querySelectorAll("[data-i18n-attr]").forEach((el) => {
    el.getAttribute("data-i18n-attr").split(",").forEach((a) => {
      const name = a.trim();
      const v = name && el.getAttribute(name);
      if (v) el.setAttribute(name, tr(i18nKey(v)));
    });
  });
}
```

## วิธีติดป้ายหน้า HTML (ใช้ใน Task 5-7)

**หลัก: ไม่เพิ่มแท็กใหม่ถ้าไม่จำเป็น** — ติดป้ายบนแท็กที่มีอยู่แล้ว เลย์เอาต์/CSS จะไม่เปลี่ยน

| เจอแบบนี้ | ทำแบบนี้ |
|---|---|
| แท็กมีแต่ข้อความ `<h2>ล็อกอิน</h2>` | `<h2 data-i18n>ล็อกอิน</h2>` |
| `<title>ล็อกอิน — Fragment Rift</title>` | `<title data-i18n>ล็อกอิน — Fragment Rift</title>` |
| ประโยคเดียวมีแท็กข้างใน `<p>เงินสด <b id="pCash"></b> ทอง · ธนาคาร <b id="pBank"></b> ทอง</p>` | `<p data-i18n-html>…เหมือนเดิม…</p>` — แท็กที่ JS เขียนค่าลงไป (`#pCash`) รอดเพราะคำแปลต้องมีแท็กเดิมครบ |
| ขึ้นบรรทัด `<h1 id="heroTitle">ออกผจญภัย<br>ได้ทุกที่ใน Discord</h1>` | `<h1 id="heroTitle" data-i18n-html>…</h1>` |
| ข้อความเปล่าข้าง ๆ แท็กลูก `<button><span class="ic">🛒</span>ตลาดผู้เล่น<span class="sub">ซื้อขายกับเพื่อน</span></button>` | ติด `data-i18n-html` ที่ตัวแม่ (`<button data-i18n-html>`) คีย์คือทั้งก้อนรวม `<span>` |
| ข้อความเปล่าอยู่ตรง ๆ ในกล่องใหญ่ที่มีปุ่ม/ช่องกรอกด้วย | ห่อเฉพาะข้อความด้วย `<span data-i18n>…</span>` — **เช็คก่อน** ว่า CSS ไม่มีตัวเลือกแบบ `.กล่อง > span` / `span:first-child` ที่จะโดนลูกใหม่ |
| แอตทริบิวต์ `title=` `placeholder=` `alt=` `aria-label=` เป็นไทย | เพิ่ม `data-i18n-attr="title"` (หลายตัวคั่นด้วยจุลภาค `"title,aria-label"`) |
| `<meta name="description" content="ไทย">` | เพิ่ม `data-i18n-attr="content"` |
| ไทยใน `href` เช่น `href="/game?codex=วิธีเล่น"` | **ไม่แตะ** — เป็นคีย์ค้นหาของหน้า game.html |

กฎที่สคริปต์บังคับ:
- `data-i18n` ห้ามมีแท็กลูก → ใช้ `data-i18n-html`
- ห้ามซ้อนป้ายใน `data-i18n-html` · ห้ามป้ายว่าง
- ป้ายหนึ่งตัว = **หนึ่งประโยค/หนึ่งป้ายชื่อ** · อย่าติด `data-i18n-html` บนกล่องใหญ่ที่รวมหลายข้อความ (คีย์ยาวเป็นย่อหน้า แปลยาก) → ติดที่ลูกแต่ละตัวแทน

**ข้อความใน `<script>` ของหน้า:**

```js
// ข้อความล้วน — แท็ก HTML อยู่นอก tr() ถ้าทำได้
box.innerHTML = "<p>" + tr("โหลดข่าวไม่สำเร็จ") + "</p>";
// มีตัวแปร → {ชื่อ} + ส่งค่าเข้าไป (ค่าที่ต้อง esc() ให้ esc ก่อนส่ง เหมือนเดิม)
el.textContent = tr("แรงค์ {rank} · เลเวล {level}", { rank: p.rank || "-", level: p.level });
// ประโยคเดียวที่มีแท็กข้างใน → แท็กอยู่ในคีย์ได้
el.innerHTML = tr("โอน <b>{amount}</b> บาท ไป PromptPay <b>{pp}</b> ({name})<br>จะได้รับ <b>🪙 {gold}</b> ทอง",
  { amount: d.amount_thb, pp: esc(d.promptpay_id), name: esc(d.promptpay_name), gold: d.gold.toLocaleString() });
// ต่อข้อความกับ error จากเซิร์ฟเวอร์
alert(tr("แนบสลิปไม่สำเร็จ: {msg}", { msg: e.message }));
// ตารางค่าคงที่ → ห่อตอนประกาศได้เลย (คำแปลโหลดเสร็จก่อนสคริปต์หน้าแล้ว)
const STATUS_TH = { pending: tr("⏳ รอตรวจ"), approved: tr("✅ สำเร็จ"), rejected: tr("❌ ปฏิเสธ") };
```

- `data.detail` / ข้อความจาก API **ปล่อยไว้** (ก้อน 2) — แค่ห่อข้อความสำรองหลัง `||`
- ห้ามแปลค่าที่โค้ดเอาไปเทียบ/ส่งกลับเซิร์ฟเวอร์ (เช่นชื่อหัวข้อคู่มือใน game.html)
